# 公開前チェック

対象: $ARGUMENTS

## 1. 対象を決める

- 引数にディレクトリか URL があればそれを使う。`--machine-only` は手順 3 を飛ばす合図なので、スクリプトには渡さない。
- 引数がなければ、プロジェクト内のビルド出力（`out/` `dist/` `build/` `public/` `_site/` など、`index.html` があるディレクトリ）を探す。見つからなければ、ビルドコマンドを確認してからビルドするか、利用者にディレクトリか URL を聞く。ソースの `.tsx` や `.astro` を直接検査しても意味がない（HTML になった結果を見る）。

## 2. 機械チェックを流す

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/launch_check.py" <ディレクトリ または URL…> [--blocklist <ファイル>]
```

- コマンドは単独で実行する（`; echo $?` や `| tail` をつなげない。つなげると事前承認の対象から外れる）。最後の行の「通過 / 要修正」と件数で結果が分かる。
- 終了コード 0 = FAIL なし、1 = FAIL あり、2 = 指定の誤り。`--strict` を付けると WARN でも 1 になる。
- 手元で配信中のサーバー（`http://127.0.0.1:…` `http://localhost:…` など）を URL で検査するときは `--allow-private` を付ける（付けないと私的アドレスとして取得しない）。ディレクトリを検査するときに公開 URL が分かっていれば `--base-url <URL>` を付けると、フォームの送信先が同じサイトかを正しく判定できる。
- `--blocklist` は、社名・本名・取引先名など公開物に出てはいけない語を1行1語で書いたファイル。利用者が持っていれば指定する。このファイルの中身は会話や報告に書き写さない。
- 出力の各行は `重さ [ルールID] ファイル:行  内容` → `該当:` → `直し方:` の順。全件が必要なら `--max-per-rule 0`、機械で読むなら `--json`。
- ルール ID の意味は README の表を見る（AI=見た目・言い回し、QA=壊れた値・仮の文言、LG=広告表示・断定・免責、SC=秘密情報、BS=基本）。

結果を読んだら:

1. FAIL を先に、ルールごとにまとめて利用者に示す。同じ原因（共通レイアウト・テンプレート）なら1件として扱う。
2. 直すのはビルド出力ではなくソース（テンプレート・コンポーネント・CSS・文言ファイル）。直したらビルドしてもう一度流し、FAIL が 0 になったことを出力で確かめる。
3. WARN は誤検知もある。意図的なもの（例: 例として使う「〇〇」、根拠を書いた No.1）は理由を添えて残してよい。毎回出るものは `--ignore <ルールID>` を使う。
4. 文言を直すときは、決まり文句を別の決まり文句に置き換えない。数字・固有名詞・手順など、そのページにしかない具体的な内容に書き換える。

## 3. レビュー担当に見てもらう

`--machine-only` のときは飛ばす。それ以外は、3つのエージェントを並行して呼ぶ。

- `launch-check:designer`: PC とスマホの実画面を撮って見た目と使いやすさを確認
- `launch-check:seo-reviewer`: 検索意図・タイトル・構造化データ・内部リンク・収益導線
- `launch-check:qa-reviewer`: 計算・数字・料率を一次資料と照合、入力の端のケース、免責

それぞれに渡すもの: 対象（ディレクトリなら `python3 -m http.server <空いているポート> --directory <ディレクトリ>` で配信した URL、または公開 URL）、ソースの場所、手順 2 の結果の要約、見てほしいページ（トップと代表ページ2〜3件）。サーバーは終わったら止める。

## 4. 報告

利用者への報告は次の順で短く書く:

1. 判定: 機械チェックの FAIL 件数と、3者の VERDICT（PASS / FIX）
2. 直したこと（ファイルと内容）と、再実行の結果
3. 残っている指摘（重い順に最大10件）。各件に場所・理由・具体的な直し方
4. 利用者にしか判断できないこと（例: No.1 表示の根拠資料があるか、販売を自分で行うか）

「公開してよい」と書けるのは、FAIL が 0 で、3者がすべて PASS のときだけ。機械チェックが通っても、それは AI が書いたかどうかの判定ではなく、法令に適合している保証でもないことを添える。
